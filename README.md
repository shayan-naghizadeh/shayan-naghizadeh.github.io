# Shayan Naghizadeh — Personal Website

Static academic portfolio for [shayan-naghizadeh.github.io](https://shayan-naghizadeh.github.io), built for GitHub Pages with semantic HTML, responsive CSS, and dependency-free JavaScript.

## Local preview

Open `index.html` in a browser, or serve the repository root with any static file server.

## GitHub Pages

Publish from the `main` branch and repository root in **Settings → Pages**. GitHub Pages serves the site without a build step.

The site intentionally lists only the Master's degree. Add a LinkedIn URL or professional email only after it is publicly available.
