CNN Digit Recognition: Software to HLS FPGA

An MNIST CNN with three convolutional and two fully connected layers, trained in Python and recreated in HLS with 16-bit fixed-point arithmetic. The implementation uses loop unrolling, pipelining pragmas, and FPGA resource monitoring; the repository documents hardware evaluation on 400 test images.

Zynq PL–PS Logic Co-design

A reconfigurable-systems project on the Arty Z7-10 / Zynq-7000 platform: a VHDL AND gate runs in programmable logic, while ARM Cortex-A9 software in the processing system performs a follow-on NOT operation. Vivado, Vitis, and AXI GPIO connect the hardware and software sides.
